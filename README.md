# Shivam Singh — Responsive Portfolio

A multi-page portfolio built with semantic HTML5, modern CSS3 and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About and skills
- `projects.html` — Selected work
- `contact.html` — Accessible contact form

## Advanced CSS3 requirements
- **CSS Grid:** hero, feature cards, projects, skills, content and contact layouts.
- **Flexbox:** navigation, buttons, footer and aligned UI components.
- **Mobile-first responsive architecture:** breakpoints at 680px and 900px, fluid typography and spacing.
- **CSS custom properties:** centralized design tokens with dark and light theme palettes.
- **Theme switching:** accessible toggle with preference retained in `localStorage`.
- **Responsive navigation:** mobile menu with `aria-expanded` state.
- **Reduced motion:** respects `prefers-reduced-motion`.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## GitHub Pages deployment
Upload the contents of this folder to the root of the existing repository and commit to `main`. Keep the `css` and `js` folders in the repository root.

## Customization note
The contact form currently uses a `mailto:` action with a placeholder address (`hello@example.com`). Replace it with your preferred email address before using the form for real messages.
